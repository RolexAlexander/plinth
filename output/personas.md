# User Personas

## PERS-001: Laundromat Customer
- **Role:** Laundromat End-User

### Goals
- Easily find an available machine without walking around
- Pay for laundry conveniently with a phone instead of coins
- Be notified when a cycle is finished without having to wait nearby
- Avoid waiting for a machine during peak hours
- Earn rewards or get discounts for being a regular customer
- Request a refund easily if a machine malfunctions

### Pain Points
- Needing to have enough coins or cash
- Losing money to machines with jammed coin slots
- Waiting around for a machine to become available, especially on busy days
- Forgetting laundry in a machine after the cycle is done
- Having to stay in the laundromat to know when a cycle is finished

### Permissions
- View a real-time map of machine availability
- Start a machine by scanning a QR code
- Pay for cycles via an app or Progressive Web App (PWA)
- Use the service as a guest without creating an account
- Create an account via email/password, Google, or Apple login
- Receive push notifications (cycle complete, reminders, promotions, waitlist)
- Earn and redeem loyalty points (registered users only)
- Purchase and use a monthly 'Spin Pass' subscription (registered users only)
- Join a virtual waitlist for a machine type
- Request a refund for a faulty cycle

## PERS-002: Dana Reeves
- **Role:** Laundromat Owner (Multi-Location)

### Goals
- Eliminate revenue loss from coin-based machine failures
- Gain real-time visibility into machine status across all locations
- Reduce maintenance costs through proactive alerts
- Increase customer loyalty and generate predictable recurring revenue
- Improve machine throughput, especially during peak hours
- Simplify bookkeeping and tax preparation with automated reports
- Provide special services like reservations for corporate clients

### Pain Points
- Losing significant revenue to coin mechanism failures
- Lack of operational visibility without being physically present
- High repair costs due to reactive maintenance
- Difficulty retaining customers and predicting revenue
- Reduced machine availability from customers leaving laundry unattended
- Time-consuming manual financial reporting

### Permissions
- View all data and functionality for all owned locations
- View an aggregate dashboard of all locations
- Access all revenue reports, analytics, and heatmaps
- Export financial and transaction data to CSV
- Configure location-specific settings, such as enabling/disabling idle fees
- Manage staff accounts and roles (Owner, Manager, Attendant)
- Approve or deny customer refund requests
- Create and manage machine reservations
- Send promotional notifications to customers

## PERS-003: Location Manager
- **Role:** Single-Location Laundromat Manager

### Goals
- Ensure the smooth daily operation of a single laundromat location
- Resolve customer issues, such as machine malfunctions, efficiently
- Monitor the financial and operational performance of the location
- Manage on-site staff and coordinate maintenance activities

### Pain Points
- Being unaware of a machine fault until a customer reports it
- Lacking data to understand the location's peak hours and machine performance
- Manually tracking maintenance issues and repairs

### Permissions
- View all data and functionality for their assigned location
- View the real-time machine status dashboard
- View revenue reports and analytics for the location
- Approve or deny refund requests for the location
- Manage the maintenance log, marking machines as 'under repair' and adding notes
- Receive maintenance alerts for faulted machines

## PERS-004: Floor Attendant
- **Role:** Laundromat Attendant

### Goals
- Quickly identify which machines need attention or are out of order
- Efficiently report machine problems to initiate the repair process
- Assist customers by providing accurate machine status information

### Pain Points
- Having to constantly walk the floor to check on machines
- Lacking a formal system to log and track reported maintenance issues
- Unable to give customers precise information about when a machine will be free

### Permissions
- View the real-time machine status map for their assigned location
- Flag a machine for maintenance in the system
- View maintenance alerts for machines at their location
- Cannot view any financial or revenue-related data
